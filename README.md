# Waves of IDEAS — Manim Source Code

Source code for all animations on the Waves of IDEAS YouTube channel.
Built using Manim Community v0.20.1 on macOS (Apple M5).

## About The Channel

Waves of IDEAS uses the IDL framework — Intuition, Demonstration, Logic —
to derive physics from first principles rather than just stating results.
Every video traces why a law has to be true, not just that it is.

## Newton's 3rd Law is a Shadow

Derives Newton's 3rd Law from momentum conservation and traces it back
to Noether's theorem via translational symmetry. Shows that every
conservation law is a symmetry of the universe in disguise — and that
some of those symmetries have limits.

### Files

* `1_intro.py` — Newton's 3rd Law setup and opening hook
* `2_deri.py` — momentum transfer derivation with vector directions
* `3_space.py` — translational symmetry demonstration
* `4_angle.py` — rotational symmetry across multiple angles
* `5_TIME.py` — time translation symmetry and energy conservation
* `6_conclusion.py` — Noether's theorem, 1st law analogy, closing argument

### Physics Covered

* Deriving Newton's 3rd Law from momentum conservation
* Why momentum is conserved — the real reason
* Noether's theorem: every continuous symmetry produces a conserved quantity
* Translational, rotational and time translation symmetry
* Why Newton's 1st Law and Noether's theorem have the exact same problem
* Where time translation symmetry breaks globally

### Requirements

* Python 3.13
* Manim Community (latest) installed in a virtual environment
* LaTeX via Homebrew
* VS Code with Manim Sideview extension
